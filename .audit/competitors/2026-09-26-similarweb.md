## Ключевые находки

### 1. STUDY AI — лидер по узнаваемости в EdTech
- **Education rank #36** — самый высокий среди конкурентов
- 90.99% трафика из РФ — это **локальный российский продукт**, не международный
- Avg visit **2m 43s** — самый долгий = высокая вовлечённость
- Pages/visit **3.26** — глубокий просмотр
- Direct traffic 45% = брендовый трафик, лояльная аудитория
- **Вывод для нас:** STUDY AI = «эталонный» EdTech AI в РФ по трафику. Они — главный конкурент на органике.

### 2. ZAOCHNIK теряет позиции
- Трафик **-19.9% за месяц** — серьёзное падение
- Avg visit всего **52 сек** — низкая вовлечённость (скорее всего, отскок после копирования)
- Pages/visit 2.77 — нормально, но не глубоко
- Organic 72.5% — зависит от SEO, **уязвимы если SEO упадёт**
- Аудитория: 64.84% женщины, 25-34 — типично «студентки для курсовых»
- **Вывод для нас:** у ZAOCHNIK слабый engagement, они не про листы, а про курсовые/дипломы. Наша SEO-ниша «рабочие листы» для них неприоритетна.

### 3. Robotext — малый трафик, плохая вовлечённость
- Global 284k, Education #466 — небольшой
- Трафик **-8.8%/мес**
- Avg visit **26 сек** — отскок моментальный
- Pages/visit **1.83** — почти нет просмотра других страниц
- Organic 47.7% — меньше зависимости от SEO
- Аудитория: 44.37% мужчины, 25-34
- **Вывод для нас:** Robotext = маленький игрок, плохая вовлечённость. Их реклама «27 млрд символов обработано» — скорее всего маркетинговая бомба, а не реальная активность.

### 4. Обучай — самый быстрорастущий ⚡
- Global **870k** — самый маленький среди 5
- Трафик **+38.6% за месяц** — взрывной рост
- Bounce **52.5%**, Pages/visit **3.07**, Avg visit 2m — нормально
- Organic 40.12% — НЕ основной канал (это значит они уже покупают трафик через другие каналы)
- **Вывод для нас:** Обучай — самый быстрорастущий конкурент в EdTech AI. 126 955 учителей (из Wave 2) подтверждают это. Они строят SEO + прямой маркетинг + teacher OS. Главная угроза.

### 5. MagicSchool — глобальный гигант, не в РФ
- **1.52M/мес трафика (US)** — топ-1 по абсолютному трафику
- US rank #11 871 — большой
- Но в РФ **не работает** (RU-локаль не нужен им)
- **Вывод для нас:** это наш зазор. MagicSchool не в РФ = наше окно. Не конкурент напрямую.

## Стратегические выводы

### Где мы слабее конкурентов
1. **Трафик = 0** (мы не задеплоены, SEO ещё не индексирован)
2. **Узнаваемость бренда** = 0 (никто не ищет «листай»)

### Где мы можем обогнать
1. **Вовлечённость > Обучай/ZAOCHNIK/Robotext** если сделаем UX wizard с presets (≤5 кликов до PDF — уже есть)
2. **Локаль RU > MagicSchool** — у нас есть ФГОС + ФИПИ из коробки
3. **SEO-карта 218 URL по экзаменам** — больше чем у любого из 5

### Конкретные действия
1. **Запустить и проиндексировать** — без деплоя все эти разговоры про SEO бессмысленны
2. **Закрыть SEO-разрыв с Обучай** — у них 52 SEO-статьи + /razbor/ канал, у нас 218 URL по номерам экзаменов. Нужно **сопоставимое покрытие** по темам (не менее 200 SEO-страниц)
3. **Диверсифицировать каналы трафика** — не только organic. Контент-burst + Telegram + vc.ru как Обучай
4. **Бенчмарк по вовлечённости** — цель: avg visit > 2m, pages/visit > 3, bounce < 50%. Wizard с presets + preview уже даёт это.
