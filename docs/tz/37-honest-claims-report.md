Скрипт ждёт на странице тарифов «Возврат в течение N дней» и «заменим или
вернём деньги», а владелец 09.10.2026 убрал обещание возврата (в FAQ теперь
«сервис предоставляется как есть, решение принимается по существу»). Скрипт и
`llms-full.txt` с этой правкой не синхронизировали. Это правовой вопрос, а не
текстовая задача — не чинил (см. §8.2).

### 7.3 Тесты не запускались из-за `NODE_ENV=production`

Описано в §2. Кратко: в песочнице `NODE_ENV=production`, при нём Vitest роняет

`Error: No such built-in module: node:` — включая существующие тесты
репозитория и те же файлы в основном дереве `/workspace/nameone`. С

Дополнительно: один прогон `tests/truthful-claims.test.ts` упал с
`Failed to start forks worker ... Timeout waiting for worker to respond` —

окружения, не теста.
