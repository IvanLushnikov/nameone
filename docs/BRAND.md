# Brand Decision — РабочиеЛисты

> Финализировано: 2026-09-25. Решение принято в чате, основа — `docs/01-research-naming.md`.
> Уточнение 2026-09-25: регистрируем **только `rabochielisty.ru`**, остальные домены не берём.

## Бренд

| Поле | Значение |
|---|---|
| **Имя** | РабочиеЛисты |
| **Подзаголовок** | РабочиеЛисты AI |
| **Домен** | `rabochielisty.ru` (единственный) |
| **Логотип** | текстовый + иконка листа A4 с клеткой от тетради + AI-акцент |
| **Палитра** | спокойный синий/зелёный + тёплый акцент |
| **Шрифт** | Inter / Golos Text (кириллица) |

## Почему это имя

- **Exact-match SEO.** «Рабочий лист по математике 5 класс дроби» — самый частотный учительский запрос в категории. Домен `rabochielisty.ru` = запрос. 240+ SEO-страниц ловят длинный хвост.
- **Учителя и родители уже гуглят это словосочетание.** Короче путь «запрос → клик», чем у неологизмов.
- **Минус «звучит как категория, не бренд»** лечится подзаголовком «РабочиеЛисты AI» и качественным продуктом.

## Альтернативы (отклонены)

- **УмныйЛист** (umnilist.ru) — fallback, если по юр. причинам имя РабочиеЛисты заблокируют. Домен **не регистрируем**. Теряем ~30–40% SEO-эффекта от exact-match.
- **Тетрадка** (tetradka.ru .com — TAKEN) — отклонена, тёплый школьный бренд, но слишком широко, не ассоциируется с worksheets.
- **ЛистAI** (listai-prototype.pages.dev) — рабочее название фронта, использовалось до решения. Уходит из бренда.

## Чек-лист после покупки rabochielisty.ru

1. Зарегать `rabochielisty.ru` на reg.ru / regery (≈600 ₽/год).
2. Настроить DNS: CNAME `rabochielisty.ru` → `listai-prototype.pages.dev` (или переименовать Pages-проект).
3. Массовая замена по чек-листу в `README.md` → раздел «Как переименовать после выбора бренда».
4. Ребилд + редеплой: `npm run build && wrangler pages deploy out`.
5. Проверить sitemap.xml + robots.txt на новом домене.
6. Добавить в Яндекс.Вебмастер после деплоя.
