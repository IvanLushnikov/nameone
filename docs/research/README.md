# Исследования продукта

Папка для отчётов **агента-исследователя** (первый агент в цепочке
«исследователь → проектировщик → разработчик»).

Промт агента: `docs/agents/AGENT-PROMPT-1-RESEARCHER.md`.

## Что здесь лежит

| Файл | Что это |
|---|---|
| `README.md` | Этот файл |
| `<NN>-<slug>.md` | Отчёт исследования: дыры, причины, способы правки |

## Формат отчёта

Обязательные разделы (подробно — в промте исследователя):

1. **Что уже работает** — с `файл:строка`. Защита от выдуманных находок.
2. **Находки** — каждая с: что видит учитель → как проверить → что подтверждает →
   причина в коде (`файл:строка`) → как починить → цена ошибки →
   что не удалось подтвердить.
3. **Улучшения** — идеи без дефекта, отдельно от находок.
4. **Что осталось неясным** — обязателен и не может быть пустым.

## Нумерация

Продолжает себя: `01`, `02`, … Проверь перед созданием:
`ls docs/research/ | sort -V | tail -3`.
