## Главное

С 1 сентября 2026 Учи.ру бесплатно делает то, за что мы берём 249 ₽: ИИ собирает задания под предмет, класс и тему 1–11 классов по ФРП 2025, даёт править результат в редакторе и отдаёт PDF. В наших документах этого нет: `01-research-naming.md` пишет «конструктора листов нет», `POSITIONING.md` — «это не наш конкурент», а база фактов от 14.10 и страницы сравнения Учи.ру не затрагивают.

Материал у нас сильный: в аудите 13.10 верны 109 ответов из 109. Проигрываем мы исполнением вокруг материала: кнопки-фасады, два источника правды для данных учителя, один поставщик нейросети, нет сквозных тестов. Исправления аудита 30.10 (включая дыру в правах и вход в любой аккаунт при ошибочной выкладке) до сих пор не в `main`.

Вывод для плана: пока база не стабильна, новые фичи не делаем. Дальше выигрываем у бесплатного Учи.ру там, где у него только задания в PDF: контрольная в двух вариантах, редактируемый DOCX/PPTX, план урока и КТП, проверка по фото, разбор класса по темам.

## УчЛист сегодня

ИИ-конструктор материалов для учителя-предметника: Next.js 14 на Cloudflare Pages, бэкенд Hono + D1, нейросети через Polza.ai. В `main` 246 коммитов, последний — `133d9af`.

### Что умеет

- Рабочие листы, тесты, контрольные в 2 вариантах, карточки, планы уроков, презентации, КТП, варианты ОГЭ/ЕГЭ, интерактивы. 21 предмет, 1–11 классы, выбор УМК.
- Экспорт в PDF, DOCX и PPTX; формулы в OMML, дроби с чертой.
- Проверка работ по фото (до 10 страниц) и «вопросы для беседы» вместо детектора ИИ.
- Онлайн-форма по ссылке и QR: ученик решает без входа, учитель видит ответы, ведомость класса и разбор по темам.
- Банк материалов и около 14 000 SEO-страниц «предмет → класс → тема».

## Учи.ру для учителя

Учи.ру берёт не материалом, а каналом и ценой: всё для учителя бесплатно, и учитель уже там ради домашних заданий и олимпиад. Качество их ИИ-заданий мы не проверяли: сайт закрыт антиботом, нужен ручной прогон под учётной записью учителя.

### Слабые места, которые видно снаружи

- ИИ обещает только «задания» и PDF. Планы уроков, КТП, контрольные в вариантах, презентации и проверка по фото в анонсе не упоминаются.
- Приложение для учителей — 4,0 в RuStore с жалобами «устанавливается, но не открывается»; детское — 3,9.
- Родители жалуются на навязчивые продажи через рейтинг класса. Часть учителей видит в Учи.ру рекламу для семьи, а не инструмент.
- Привязка к их экосистеме: чтобы скачать, нужна регистрация учителя на платформе.

### Возражения учителя и ответы

- «В Учи.ру то же самое бесплатно» → «Там задания в PDF. У нас контрольная в двух вариантах, план урока и КТП в Word, а потом проверка тетрадей по фото».
- «У них по ФРП, а у вас?» → «По ФГОС и вашему учебнику: Моро, Виленкин, Мерзляк». До этого нужно закрыть задачу про ФРП из бэклога.
- «Зачем платить 249 ₽?» → «Пять материалов в месяц бесплатно, проверка по фото и разбор ответов квоту не тратят».

### Чего не делать

- Не спорить с Учи.ру ценой и шириной банка — это не выиграть.
- Не обещать в сравнении того, что не проверено вживую у них и у нас: команда уже держит правило «честных текстов» (ТЗ-30, ТЗ-32).

## Планка качества

Задача принимается только тогда, когда метрика ниже измерена на проде, а не в юнит-тесте. Сейчас большинство из них никто не считает — это первый пробел.

| Метрика | Сейчас | Цель | Владелец |
| --- | --- | --- | --- |
| Генерации без ошибки с первой попытки | не измеряется (цель в POSITIONING — 80%) | ≥ 98% | Бэкенд |
| Время листа, p95 | 30–42 с по аудиту | ≤ 45 с, первое задание на экране ≤ 10 с | Бэкенд |
| Время контрольной, p95 | 96–102 с | ≤ 60 с | Бэкенд |
| Дубли навыка в листе | 3 листа из 8; узкая тема — \~50% | ≤ 1 лист из 20 на эталонном наборе | LLM-слой |
| Верные ответы | 109 / 109 | 100% на эталонном наборе в каждом релизе | LLM-слой |
| Кнопки без серверного действия («фасады») | минимум 4 по аудиту 30.10 | 0; каждая покрыта e2e | Фронт |
| Главные сценарии в e2e, блокирующие выкладку | 0 | 6 сценариев | QA |
| Горизонтальный скролл на 360–390 px | 0 после ТЗ-26 | 0 на всех экранах, проверка в CI | Дизайн + фронт |
| Контраст текста и кнопок | кнопки 5,75:1; вторичный текст не перепроверен | ≥ 4,5:1 везде | Дизайн |
| Доступность при сбое поставщика нейросети | 0% | генерация идёт через запасного | Бэкенд |
