# Тест-кейсы для проверки правок по аудитам — 11 октября 2026

Кейсы пишутся под план `docs/30-audit-plan-2026-10-11.md`.
Каждый блок закрывается только когда все его кейсы зелёные. Кейс считается пройденным,
только если агент-верификатор увидел результат своими глазами: вывод команды, скриншот
или файл сборки. «Должно работать» — не результат.

Общие проверки для всех блоков (Г-1…Г-4) прогоняются один раз в конце.
