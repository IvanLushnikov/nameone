## A. ФГОС-паттерны

### Obuchai.com (прямой конкурент)
- **Маркировка ФГОС**: нет визуальной плашки «ФГОС» на карточках. ФГОС упоминается в hero-тексте: «задания по ФГОС за минуту», «по федеральной рабочей программе вашего предмета и класса», FAQ-блок «Рабочие листы соответствуют ФГОС? Генератор опирается на федеральные рабочие программы».
- **ФИПИ / спецификация**: упоминается явно. «Для 9 и 11 классов есть форматы ОГЭ и ЕГЭ по спецификациям ФИПИ 2026». Лист можно собрать «по номерам КИМ ОГЭ или ЕГЭ 2026 — по спецификациям ФИПИ, с реальными номерами заданий и баллами».
- **Кодификатор / программа / учебник**: «федеральные рабочие программы» — да; явных ссылок на конкретные УМК (Моро, Виленкин) нет.
- **Соответствие стандарту**: 70 типов заданий, 1-11 класс, 65+ предметов, PDF/DOCX/PPTX, шаблоны «Экономия тонера», QR-выдача.
- **JSON-LD `knowsAbout`**: ФГОС, федеральные рабочие программы, рабочие листы, презентации к урокам, планы уроков, ОГЭ, ЕГЭ, ВПР, ИИ в образовании.

### Pervoklass.com
- **Маркировка ФГОС**: **отсутствует**. Никаких меток/плашек/упоминаний ФГОС на главной и в материалах. Только общее «по школьной программе» и «готовые задания по школьной программе» в SEO-текстах.
- **ФИПИ / кодификатор / спецификация**: нет.
- **УМК**: нет.
- **Параллельный бренд**: 4 формата материалов (раскраски, рабочие листы, прописи, тренажёры), 3 предмета (Азбука, Математика, Русский язык), 1-4 класс. SEO-стратегия — массовый длинный хвост под события/темы.

### Videouroki.net
- **Маркировка ФГОС**: явный фильтр в каталоге. Кнопка «ФГОС» в группе `data-filter-group="fgos"`. На карточках — классы `.fgos` в CSS-фильтрах (`class="shop-products__item fgos videouroki class6"`).
- **ФИПИ**: в каталоге есть отдельный раздел «Подготовка к ЕГЭ, ОГЭ» (`/catalog/152/`).
- **УМК**: каждый комплект явно пишет «Сочетается с любыми УМК и программами». УМК не привязан как зависимость — материал совместим со всеми.
- **Кодификатор / программа**: формат комплектов = «на весь учебный год», «видеоуроки + тесты + презентации».
- **Структура фильтров**: 3 группы — тип (видеоуроки / электронные тетради), ФГОС (все / ФГОС), класс (1-11). Это **best practice** для таксономии.
- **Виджет «версия для слабовидящих»** — accessibility-фишка, ни у кого больше не видел.

### Yaklass.ru (yaklass.by)
- **Маркировка ФГОС**: да. Главная: «Используйте материалы, соответствующие ФГОС и ФООП, на каждом уроке». В коде: упоминание «Федеральные государственные образовательные стандарты» в Schema.org.
- **ФИПИ / УМК**: на yaklass.by не вижу кодов ФИПИ/кодификатора в публичной части. УМК поддерживаются, но детали скрыты за логином.
- **Разделение ролей**: «Учителям», «Ученикам», «Родителям» — каждое со своим интерфейсом (отдельные URL `go.yaklass.ru` / `class.uchi.ru` и т.п.).
- **Категории**: иконки предметов с уникальными цветами. Конкурсы и ТОПы — отдельный engagement-loop.

### Uchi.ru
- **Маркировка ФГОС**: да, на главной: «Материалы соответствуют ФГОС и ФООП». Это заявлено в первом экране.
- **ФИПИ / УМК**: «Курсы входят в перечень ЭОР Минпросвещения России». Поддержка УМК — через выбор программы (`/podgotovka-k-uroku` → класс → предмет → программа → урок). Поддерживаются Школа России, Перспектива, Начальная школа XXI века и т.д.
- **Разделение ролей**: 4 личных кабинета — учитель, ученик, родитель, завуч.
- **Параллели**: «88% школ страны используют Учи.ру» — главная социальная метрика.
- **Структура каталога**: класс → предмет → программа → тема (3 уровня).

### Reshuege / Sdamgia
- **Маркировка ФГОС**: нет ярлыка. Сайт изначально построен вокруг **КИМ ФИПИ**, поэтому всё соответствие ФГОС имплицитно через структуру экзаменов.
- **ФИПИ / спецификация**: главная сущность. Каждый предмет разложен на ЕГЭ (база/профиль) / ОГЭ / ВПР / ГВЭ / ЦТ / ЕНТ / Олимп.
- **Кодификатор**: номера заданий = коды кодификатора ФИПИ (например, «задание №1, №2, …, №27»). Структура точно повторяет спецификацию.
- **УМК**: нет привязки.
- **Категории**: по предметам, по экзаменам. Огромная библиотека заданий по каждой теме.

### **Общие паттерны**

**Что повторяется у 4+ конкурентов (must have):**
- ✅ Упоминание «ФГОС» или «ФООП» в hero и SEO. **Никто не делает визуальную плашку «ФГОС»** на карточках материала, кроме videouroki.net (там это фильтр-чип).
- ✅ ФИПИ упоминается у всех, кто работает с ОГЭ/ЕГЭ (obuchai, videouroki, sdamgia, yaklass).
- ✅ Разделение «Учителю / Ученику / Родителю» (yaklass, uchi.ru, obuchai, videouroki регистрация с выбором «Ученик/Учитель/Родитель»).
- ✅ Категоризация по предметам + классам — у всех шестерых.
- ✅ Генератор задач по теме (не по УМК) — у obuchai, videouroki, yaklass (выбор темы), uchi (по программе).

**Что уникально у 1-2 конкурентов:**
- 🔹 **Videouroki**: явный фильтр «ФГОС» + классы. Лучшая фильтрация каталога из всех.
- 🔹 **Uchi.ru**: 88% школ РФ — социальное доказательство; обязательная привязка к УМК через «программу».
- 🔹 **Obuchai**: «70 типов заданий», «65+ предметов», «ФИПИ 2026 спецификации», «Честно о рамках» (явно признают ограничения AI).
- 🔹 **Sdamgia**: 100% привязка к номерам КИМ ФИПИ; единственный, кто реально структурирует по номерам заданий, а не по темам.
- 🔹 **Yaklass**: ТОПы, рейтинги, геймификация (⭐).
- 🔹 **Videouroki**: версия для слабовидящих — accessibility-фишка.

## C. Структурные паттерны

### **Категоризация**

| Конкурент | Главная категория | Вторичная | Третичная |
|---|---|---|---|
| **Obuchai** | По типу материала (листы/презентации/планы/тесты) | По предмету | По классу |
| **Pervoklass** | По типу (раскраски/листы/прописи/тренажёры) | По предмету | — |
| **Videouroki** | По типу материала (комплекты/курсы/тесты/тетради/видеоурок/разработки) | По предмету | По классу + ФГОС-фильтр |
| **Yaklass** | По предмету (24+ предмета) | По классу | По теме |
| **Uchi.ru** | По классу → по предмету → по программе (УМК) → по теме | — | — |
| **Sdamgia** | По предмету (16 предметов) → по экзамену (ЕГЭ/ОГЭ/ВПР/ГВЭ/ЦТ) → по теме | По номеру КИМ | — |

**Главный вывод**: **никто не категоризирует ТОЛЬКО по предметам без параллели класс/УМК**. Лучшая категоризация = **тип материала × предмет × класс** (трёхмерная матрица).

### **Каталог тем**

- **Obuchai**: генерируется через «тема + класс + предмет» в свободной форме, нет жёсткой иерархии тем
- **Pervoklass**: темы привязаны к событийному календарю («День учителя», «22 августа — День флага РФ»), сезонные, ~50 тем в каталоге
- **Videouroki**: 30 видеоуроков + 30 тестов + 30 презентаций в каждом комплекте, **тема урока зашита в комплект** (на учебный год)
- **Yaklass**: темы в иерархии «предмет → класс → раздел → тема → упражнение» (самая структурированная)
- **Uchi.ru**: темы привязаны к уроку = «параграф учебника»
- **Sdamgia**: темы = разделы кодификатора ФИПИ

### **УМК-поддержка**

| Конкурент | УМК поддерживаются? | Как выражено |
|---|---|---|
| Obuchai | ❌ нет (только «по федеральной программе») | «Соответствует ФГОС», но без выбора учебника |
| Pervoklass | ❌ нет | — |
| Videouroki | ✅ частично | «Сочетается с любыми УМК и программами» |
| Yaklass | ✅ да | за логином, в настройках урока |
| **Uchi.ru** | ✅ **полная** | обязательный выбор программы: Школа России / Перспектива / Начальная школа XXI века и т.д. |
| Sdamgia | ❌ нет | привязка к ФИПИ, не к УМК |

**Главный вывод**: **Uchi.ru — единственный, кто ОБЯЗЫВАЕТ выбрать УМК**. Это teacher-intent killer feature: «Моро 3 класс рабочий лист» приводит к конкретной программе.

## D. UI-фишки которые стоит спиздить (TOP 10)

1. **🥇 Обязательный выбор УМК (Uchi.ru)** — после выбора предмета и класса показывать 4-5 УМК (Моро/Виленкин/Мерзляк для математики, Ладыженская/Разумовская для русского). Привязка генерации к конкретному УМК = уникальный SEO + teacher-intent killer.

2. **🥇 «Тема недели» / привязка к календарю (Pervoklass)** — рабочие листы на текущую неделю («День учителя», «22 августа — День флага РФ», «Новогодние задачи»). Pervoklass на этом строит весь контент-маркетинг и SEO. Сезонность → повторный трафик.

3. **🥇 Разделение «Учителю / Ученику / Родителю» в сайдбаре (Yaklass, Uchi.ru, Obuchai)** — у нас сейчас общий лендинг. Нужны отдельные прелендинги или переключатель ролей с релевантным контентом.

4. **🥈 «Каникулы 2026/2027» (Obuchai)** — контентная страница-календарь со ссылками на листы по темам четвертей/полугодий. Чисто SEO-фишка, даёт трафик перед каникулами.

5. **🥈 «Тематические дни» / событийный календарь (Pervoklass, Obuchai)** — ежедневный/еженедельный контент, привязанный к памятным датам РФ. Каждый день = новый лист. Viral-механика для соцсетей.

6. **🥈 Чек-лист «Что проходят сейчас в школах»** (не нашёл готового — изобретаем). На главной блок «В октябре 5-е классы проходят: дроби, Пушкин, климатические пояса» с быстрым переходом к генерации. Сезонный трафик.

7. **🥈 Готовые рабочие программы / КТП (Obuchai: «План урока и технологическая карта»)** — teacher-intent killer: «КТП по математике 5 класс 2026-2027» = тысячи поисков в августе-сентябре. Конвертируется в подписку.

8. **🥉 QR-код + онлайн-выдача по ссылке (Obuchai)** — лист можно выдать классу без печати: ученик решает с телефона, ответы проверяются автоматически. Это **выводит нас из категории «PDF-only» в «живая проверка»** — сильное конкурентное отличие.

9. **🥉 Баллы ОГЭ в оценку / Калькулятор СОУ (Obuchai: «Качество знаний и СОУ»)** — микро-инструменты, которые собирают SEO-трафик («баллы ОГЭ в оценку 2026», «СОУ калькулятор»). Лёгкие в реализации, приводят учителя в воронку.

10. **🥉 «Словарные слова 1-4 класс» (Obuchai)** — тематический микро-инструмент. Словарные слова — топовый teacher-intent запрос, идеально для привлечения на лендинг и вовлечения в генерацию.

## E. Рекомендация что внедрить в первую очередь (для РабочиеЛисты AI / ЛистAI)

Приоритизация по P×I×V (Pain × Impact × Velocity):

## Блокеры / допущения

- **Yaklass.ru** и **Uchi.ru** заблокировали прямой fetch (Cloudflare + ServicePipe). Данные по ним собраны через `yaklass.by` (тот же каталог предметов) и поисковые сниппеты.
- **Pervoklass.com** блокирует AI-скрейпинг через `CONFIDENTIAL & PROPRIETARY` заголовок. Данные собраны только из публичной главной страницы и SEO-текстов — структура конструктора `https://pervoklass.com/konstruktor` не подтверждена (отдаёт 404).
- **Videouroki.net** — данные собраны из `/catalog/` (полный каталог с фильтрами), главной и нижнего колонтитула.
- **Точные объёмы тем** (количество тем в каждом предмете у конкурентов) — не измерял. Для yaklass/sdamgia — тысячи; для uchi.ru — десятки тысяч; для pervoklass — десятки наборов. Для нас (ЛистAI) текущий объём: 15 предметов × ~40 тем = ~600 тем (см. `src/lib/content/subjects.ts:1`).
- **Приоритизация UI-фишек** — экспертная оценка по teacher-intent + конкурентному зазору, не по метрикам (нет доступа к Метрике конкурентов).
- **Часть рекомендаций (онлайн-выдача, КТП)** требует backend-разработки и не может быть сделана только на фронте Next.js static export — нужна миграция или внешний BaaS (Supabase / Firebase).
