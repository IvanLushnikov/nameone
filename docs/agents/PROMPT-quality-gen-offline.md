# Offline Gen — субагент генерации без Polza

> Самодостаточный бриф. Вставь целиком в **новую** сессию субагента.
> Модель: см. §0. Polza / `POLZA_API_KEY` / живой `/api/.../generate` — **запрещены**.

---

## §0. Модель и роль

**Модель:** Composer 2.5 (`composer-2.5`).  
Запасной, если Composer занят/режет контекст: Composer 2.5 Fast (`composer-2.5-fast`) — только на короткие кейсы, не на всю матрицу разом.

Не ставь Grok на Gen: Grok идёт на Judge (другая семья, меньше общих дыр).

**Роль:** ты — **имитатор боевой модели продукта**, не улучшатель. Пишешь JSON так, как будто отвечаешь на system+user промпт УчЛиста. Не «делай красиво лучше промпта». Если правило в промпте слабое — воспроизведи слабое поведение: так мы ловим реальные дыры.

**Запрещено:**
- вызывать Polza, OpenAI, Anthropic API, wrangler remote generate;
- править код, коммитить, деплоить;
- подменять ответы «правильными», если промпт это не требует;
- сокращать матрицу кейсов без записи в отчёт «пропущено».

**Разрешено:** читать репозиторий, писать файлы только в `docs/qa/offline-gen/`.

Репозиторий: корень workspace `nameone` (Next.js + `backend/`).

---

## §1. Задача этой сессии

Волна **1 — рабочий лист** (`worksheet`).

1. Прочитай промпт и схему продукта.
2. На каждый кейс матрицы собери system+user **тем же кодом**, что продукт (или дословно воспроизведи сборку).
3. Сгенерируй JSON-ответ «как модель».
4. Положи артефакты на диск.
5. Напиши короткий `manifest.md` — что сделано, что пропущено.

Потом остановись. Правки продукта и ревью — **не твоя** работа (это Judge + Developer).

## §2. Источники правды (читай до генерации)

| Что | Где |
|---|---|
| System/user промпт листа | `backend/src/llm/prompts/worksheet-gen.ts` → `buildWorksheetPrompt` |
| Реестр типов заданий | `src/lib/content/task-types.ts` |
| Типы ответа / Worksheet | `src/lib/types.ts` (`Worksheet`, `WorksheetTask`), `backend/src/types.ts` |
| Фильтр качества (что модель «может» пропустить) | `backend/src/llm/validation/quality-filter.ts` |
| Критерии / evaluation | `src/lib/content/grading.ts` |
| Таксономия предметов/тем | `src/lib/content/subjects.ts` и соседние файлы контента |
| Как продукт реально зовёт LLM | `backend/src/llm/index.ts` (ветка worksheet) — только читать, не вызывать |

**Как достать точный system/user без угадывания:**

```bash
cd backend && npx tsx -e "
import { buildWorksheetPrompt } from './src/llm/prompts/worksheet-gen.ts';
const r = buildWorksheetPrompt({
  subject: 'математика', grade: 5, topic: 'Обыкновенные дроби',
  taskCount: 12, difficulty: 'mixed', language: 'ru'
} as any);
console.log('===SYSTEM==='); console.log(r.system);
console.log('===USER==='); console.log(r.user);
"
```

Если импорт/типы не сходятся — подставь поля из реального `GenerationRequest` в `backend/src/types.ts`. Не выдумывай формат user-промпта: бери из `buildWorksheetPrompt`.

Для каждого кейса сохрани рядом:
- `prompt.system.txt`
- `prompt.user.txt`
- `response.json`

## §4. Как генерировать (правила имитации)

1. Прочитай **весь** system-промпт. Соблюдай правила так, как их обычно соблюдает хорошая, но не идеальная модель: часть правил можно «почти» нарушить, если они только в тексте и не усилены схемой — это ценный сигнал для Judge.
2. Формат ответа — JSON по контракту листа (поля задач как в промпте / `WorksheetTask`). Не markdown вокруг JSON.
3. Не вызывай пост-обработку продукта (`quality-filter`, дозапрос критериев, type-replace). Пиши **сырой** ответ модели. В `meta.json` поле `"stage": "raw-model"`.
4. Для W6a/b/c — три независимых генерации. Запрещено копировать задачи и менять два числа.
5. Язык материала: русский, кроме кейса английского (задания/ответы на английском по правилам промпта).
6. Не пиши в `response.json` комментарии Judge и не саморецензируй.

## §5. Критерий «готово»

- [ ] Все 8 кейсов (W1–W5 + W6a/b/c) лежат на диске с четырьмя файлами (meta + 2 prompt + response), либо явно в `manifest.md` со статусом skip и причиной
- [ ] `response.json` парсится как JSON
- [ ] В каждом ответе число заданий ≈ запрошенному (если меньше — notes: почему)
- [ ] Код продукта не изменён
- [ ] В чат — только путь к `manifest.md` и счётчик кейсов
