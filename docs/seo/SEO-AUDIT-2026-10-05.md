# SEO-аудит «УчЛист» — 5 октября 2026

Аудит проведён по репозиторию `nameone` (Next.js 14, статический экспорт) и по живым страницам
`https://listai-prototype.pages.dev/`. Код проекта не изменялся.

---

## 1. Вердикт

**СЕЙЧАС SEO — СРЕДНЕЕ, с рискованной верхней границей.** Техническая база реально собрана лучше
среднего по рынку: 3901 страница в sitemap, `lang="ru"`, 3882 корректных `BreadcrumbList`,
`Organization` + `WebSite` + `FAQPage` на главной, `LearningResource` на 2883 страницах, рабочий
`robots.txt` со ссылкой на sitemap, 404 отдаётся корректно. Но три обстоятельства сейчас
обнуляют пользу этой базы:

1. **Весь SEO-вес привязан к временному домену** `listai-prototype.pages.dev`, а не `uchlist.ru`
   (`src/lib/site.ts:8`, `.github/workflows/deploy.yml:71`).
2. **59% страниц из sitemap — «сироты»**: 2288 из 3901 URL не имеют ни одной входящей внутренней
   ссылки с сайта.
3. **Содержание однотипное**: медиана текста на странице темы — 2175 знаков, у 2140 страниц
   `/lesson-plan/*`, `/presentation/*`, `/ktp/*` разброс между минимумом и максимумом — сотни
   знаков при медиане ~2100. Это шаблон, а не материал.

Плюс к этому аналитика **подключена** (вопреки заявлению в брифе и в roadmap) — счётчик Метрики
`113327591` реально грузится на лайве. Не подключены только Вебмастер и GSC — это проверить
снаружи нельзя, чек-лист `docs/seo/seo-checklist-step5.md` содержит незакрытые чекбоксы.

**Главный риск — не отсутствие фич, а масштаб.** 3901 страница при нулевой авторитетности домена
и шаблонном контенте — это ровно тот профиль, который Яндекс и Google сворачивают целиком
(«массовый тонкий контент / doorway»), а не постранично.

## 7. Границы проверки

- Проверял по локальной сборке `out/` (3917 страниц) и по живым ответам сайта. Локальная сборка
  чуть устарела относительно лайва (3901 против 3916 URL в sitemap) — расхождение в 15 URL на

- **Google Search Console и Яндекс.Вебмастер снаружи недоступны** — подтверждён ли домен и подавался
  ли sitemap, из этой сессии проверить нельзя. Чек-лист `seo-checklist-step5.md` показывает
  незакрытые пункты, но это запись в документе, а не факт из панели.
- Запросы проверены через DuckDuckGo (US-индекс). **Данных по выдаче Яндекса в этой сессии нет** —

  существенная оговорка: вывод «нас нет в топ-10» подтверждён по одному поисковику.
- Скорость (Lighthouse, Core Web Vitals) не измерялась — доступны только веса HTML и чанков.
