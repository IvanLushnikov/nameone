## §1. Результат — что получим через 6 месяцев

### 1.1 Бизнес-цель
Стать **первым результатом в Яндексе и Google** по запросам вида:
- «рабочий лист математика 5 класс дроби»
- «тест русский язык 6 класс причастие»
- «карточки по ФГОС 3 класс»
- «ИИ для учителя рабочие листы»
- «генератор рабочих листов»
- «ОГЭ 9 класс математика вариант»
- «КТП русский язык 5 класс ФГОС 2026»

### 1.2 Целевые метрики (KPI) — 6 месяцев

| Метрика | Сейчас (оценка) | Через 3 мес | Через 6 мес |
|---|---|---|---|
| Organic clicks/день (Я + G) | <10 | ≥100 | ≥500 |
| Страниц в индексе (Яндекс) | <50 | ≥150 | ≥400 |
| Страниц в индексе (Google) | <30 | ≥200 | ≥600 |
| Lighthouse Performance (моб.) | n/d | ≥85 | ≥90 |
| Domain Rating / DR (ahrefs) | ~0 | ≥5 | ≥15 |
| Referring domains | <5 | ≥15 | ≥40 |
| Доля brand-запросов в органах | n/d | ≤50% | ≤30% |
| Доля Top-3 запросов (Я + G) | 0 | ≥10 | ≥40 |

Если к 6-му месяцу organic < 100 кликов/день — стратегия пересматривается (см. §11).

### 1.3 Что НЕ является целью
- Не «получить 100к трафика любой ценой». Только релевантный учительский трафик.
- Не «забить SERP мусорными страницами». Не дублировать темы, не плодить doorway-страницы.
- Не «обогнать Инфоурок в бренд-запросах». Их brand awareness несопоставим. Фокус — long-tail.

## §4. Кластеры запросов и стратегия по ним

### 4.1 Карта кластеров (topical authority)

Мы строим **тематический авторитет** в 4 кластерах, по убыванию приоритета:

| Кластер | Тип запросов | Объём (оценка, шт/мес) | Приоритет | Целевые страницы |
|---|---|---|---|---|
| **A. Рабочие листы по [предмет] [класс]** | exact-match, high-intent | ~120 000 | 🥇 P0 | `/subject/[s]/[g]/[t]/` (есть 660+) |
| **B. Рабочие листы / карточки / тесты (общие)** | broad, верх воронки | ~95 000 | 🥇 P0 | Главная + Blog |
| **C. ИИ для учителя / генератор листов** | категорийные, конкурентные | ~30 000 | 🥈 P1 | Blog + сравнительные страницы |
| **D. ОГЭ/ЕГЭ варианты и подготовка** | сезонные (январь-июнь), high-intent | ~180 000 | 🥇 P0 | `/exam/...` + `/oge` + Blog |
| **E. План урока / презентация / КТП** | широко, средний конкурент | ~60 000 | 🥈 P1 | `/lesson-plan/...`, `/presentation/...`, `/ktp/...` (есть) |
| **F. ФГОС / нормативная база** | информационные, низкая монетизация | ~25 000 | 🥉 P2 | Blog |

**Метрика успеха:** Top-3 в Яндексе по запросам формата «рабочий лист {предмет} {класс} {тема}» за 6 мес.

## §5. Технические улучшения — паттерны и правила

### 5.1 Метаданные (per-page)

Правила для **каждой** ключевой страницы (тема, предмет, класс, exam, theme):

| Поле | Лимит | Формула |
|---|---|---|
| `<title>` | ≤60 символов | `{topic.title} — рабочие листы · {subject.shortTitle} {grade} класс` |
| `<meta description>` | 155-160 символов | Что получит + сколько времени + 1 power word |
| `<meta keywords>` | 5-7 слов | убрать, Яндекс не использует, Google — слабо |
| `canonical` | 1 на страницу | абсолютный URL, на себя |
| `og:title` | ≤60 символов | = `<title>` |
| `og:description` | ≤160 | = `<meta description>` |
| `og:image` | 1200×630 | **новое** — генерировать для каждой темы (см. §5.4) |
| `og:type` | — | `article` для темы, `website` для главной/хаба |
| `twitter:card` | — | `summary_large_image` |
| `article:author` | — | «Команда УчЛист» |
| `article:published_time` | ISO 8601 | дата первой публикации темы (фиксируем в `topics.ts`) |
| `article:modified_time` | ISO 8601 | при каждом обновлении контента |

Текущая тема: title и description ок, но:
- Title: «Дроби обыкновенные — рабочие листы · Математика 5 класс» — **уже в норме** (~60 символов).
- Description содержит «30 секунд» — хорошо.

**Что менять:**
1. Главная: title сейчас «УчЛист — рабочие листы и тесты по ФГОС за 30 секунд» — **60 символов ровно**, впритык. Сократить: «УчЛист — рабочие листы по ФГОС за 30 секунд» (52 символа).
2. Главная: description сейчас ~175 символов — **длинновато**, сократить до 158.
3. На каждой теме добавить `og:image` + `article:published_time` + `article:modified_time`.
4. На каждой теме добавить `canonical: ${base}/subject/${s}/${g}/${t}` (на случай query params).

### 5.2 Schema.org / JSON-LD — что добавить

| Тип страницы | Что есть | Что добавить (P0-P1) |
|---|---|---|
| Главная `/` | — | P0: `Organization` (с logo, contacts, sameAs), `WebSite` (с `SearchAction`) |
| Предмет `/subject/[s]` | — | P0: `CollectionPage`, `BreadcrumbList`, `ItemList` (со ссылками на темы) |
| Класс `/subject/[s]/[g]` | — | P0: `CollectionPage`, `BreadcrumbList` |
| Тема `/subject/[s]/[g]/[t]` | `LearningResource` + `educationalAlignment` | P0: `BreadcrumbList`, `FAQPage`. P1: `Quiz` для примеров заданий |
| Lesson-plan | — | P1: `HowTo` (шаги урока) + `Course` (опционально) |
| Presentation | — | P1: `Course` |
| КТП | — | P1: `Course` с `hasCourseInstance` |
| Exam `/exam/...` | — | P1: `Quiz`, `Question` (если есть готовые задания) |
| Theme `/theme/[slug]` | — | P0: `Article` с `datePublished` + `author` |
| Pricing `/pricing` | — | P0: `Product` + `Offer` (один или несколько — по тарифам) |
| Blog post | — | P0: `BlogPosting` + `BreadcrumbList` + `author` |

Все JSON-LD через единый компонент `<JsonLd data={...} />` в `src/components/seo/JsonLd.tsx`. Не дублировать `<script type="application/ld+json">` в каждой странице.

### 5.3 Sitemap — что улучшить

Текущий sitemap (TZ-06) уже покрывает ~660+ URL. Что добавить:

1. **Sitemap index** — разделить на несколько файлов, если > 5 000 URL (пока не критично).
2. **`lastmod`** — на каждом URL добавить дату последнего изменения (Next.js подхватит из кеша).
3. **Image sitemap extension** (опционально, если добавим иллюстрации на темы).
4. **News sitemap** — только если заведём блог с регулярным свежим контентом.

**Действия:**
- В `sitemap.ts` добавить `lastModified: new Date()` для static-страниц и дату обновления контента для тем (хранить в `topics.ts` или БД).
- После P0: добавить blog sitemap отдельно.

### 5.4 OG-image — автогенерация

**Проблема:** сейчас og:image дефолтный или отсутствует. SERP и соцсети будут показывать пустое превью.

**Решение:** `@vercel/og` (или `next/og`) + Edge-функция `src/app/og/[...slug]/route.ts`:
- URL: `/og/math/5/drobi` → возвращает PNG 1200×630 с темой, предметом, классом, логотипом.
- Шрифт: Inter (он уже подключён).
- Кеш: `Cache-Control: public, max-age=86400, immutable`.
- Fallback: дефолтный og на главной — лого + слоган.

**Файлы:**
- `src/app/og/[...slug]/route.tsx` — генератор.
- Обновить `generateMetadata` на теме/предмете/классе — добавить `openGraph.images`.

**Приоритет:** P0 (без og:image SERP-превью выглядит бедно).

### 5.5 Robots — что улучшить

Текущий:
```
{ userAgent: "*", allow: "/", disallow: ["/api/", "/dashboard", "/preview/"] }
```

**Что добавить:**
1. Host directive: `Host: https://uchlist.ru`.
2. Yandex-specific: можно оставить общий, но проверить, что Яндекс.Бот не упирается в `/api/`.
3. Crawl-delay для непроверенных ботов (Googlebot, Yandex — без задержки).
4. `Disallow: /api/`, `/dashboard`, `/preview`, `/admin`, `/login`, `/auth/callback/`. Уже частично закрыто.

### 5.6 PageSpeed / Core Web Vitals

**Целевой LCP < 2.5s, CLS < 0.1, INP < 200ms** на мобиле (3G, Moto G Power).

Действия:
1. Lighthouse + PageSpeed Insights прогон на 5 ключевых страницах (главная, тема, exam, pricing, blog-post) — **до старта работ**.
2. Image optimization: все иллюстрации на темах — через `next/image` (WebP, AVIF, srcSet).
3. Шрифт: Inter уже через `next/font` с `display: swap` — ✅.
4. JS bundle: текущий next build (см. build-логи) — если > 200 KB на главной, разбить.
5. Server Components / RSC — не увёртывать клиентские компоненты без нужды.
6. CDN: Cloudflare Pages (если ещё не) — включить HTTP/3, Brotli, cache headers.

**Приоритет:** P0 для главной и темы (там больше всего трафика).

### 5.7 Hreflang / canonical

- hreflang **не нужен** — мы только ru.
- canonical: на каждой странице (включая query-params варианты) — Next.js автогенерит, проверить в `<head>` после билда.

## §6. Контентные улучшения

### 6.1 Перелинковка на теме

Каждая тема должна иметь **3-5 внутренних блоков ссылок**:
1. «Другие темы {grade.num} класса по {subject.shortTitle}» — все темы того же класса × предмета.
2. «{subject.shortTitle} в соседних классах» — этот же предмет в ±1 классе (4-7 ссылок).
3. «Часто ищут с темой «{topic.title}»» — related searches (генерим из LLM или руками).
4. «Все рабочие листы по {subject.shortTitle}» — ссылка на subject hub.
5. «Подготовка к ОГЭ/ЕГЭ» — если применимо (для 9/11 классов).

**Реализация:**
- Компонент `<RelatedTopics currentTopic={t} grade={g} subject={s} />` в `src/components/seo/RelatedTopics.tsx`.
- Reuse в lesson-plan / presentation / exam.

### 6.2 FAQ на теме / предмете

На каждой теме — блок «Часто задаваемые вопросы» + JSON-LD `FAQPage`:
- 3-5 вопросов (генерим шаблонно: «Сколько заданий в листе?», «Есть ли ответы?», «Какой формат?», «Подходит для какой программы?»).
- На предметных хабах — 5-8 вопросов по предмету («Какие классы покрыты?», «Есть ли ОГЭ-варианты?»).
- На главной — 5-7 вопросов про сервис в целом.

### 6.3 Blog (Content Hub)

**Зачем:** broad-запросы кластера B + сезонный трафик кластера D + long-tail по темам, которые не лезут в основной sitemap.

**Структура:**
- `/blog/` — список постов с пагинацией (по 12 на странице).
- `/blog/[slug]` — отдельный пост.
- Категории: «По предметам», «По классам», «ОГЭ/ЕГЭ», «Для учителя», «Лайфхаки».
- Теги: свободная система.

**Контент-план на 12 месяцев:**

| Месяц | Темы (штук) | Цель |
|---|---|---|
| Q4 2026 (старт) | 4 поста в месяц (16) | Запустить блог, наполнить первичным контентом |
| Q1 2027 | 6 постов/мес | Подготовка к ОГЭ/ЕГЭ — сезон, ловим трафик |
| Q2 2027 | 4 поста/мес | Удержание, кейсы учителей |

**Типы постов:**
- «Как подготовить рабочий лист по теме X за 5 минут» — how-to (кластер A).
- «ОГЭ по математике 2027: что изменилось» — инфо-сезонное (D).

**SEO-параметры поста:**
- Title: ≤60 символов, содержит главный ключ.
- Description: 155-160 символов.
- OG-image: свой (генерим по правилам §5.4).

- Иван (PM) — задаёт темы и редактуру.
- Mavis — пишет черновики, делает research, проверяет ключевики.

## §11. Риски и антипаттерны

### 11.1 Риски

| Риск | Вероятность | Импакт | Митигация |
|---|---|---|---|
| Обучай / Инфоурок закроют нишу раньше, чем мы наберём обороты | Средняя | Высокий | Фокус на длинный хвост + учитель-FL, не конкуренция в бренд-запросах |
| Google/Яндекс ужесточат правила для AI-контента | Средняя | Высокий | Генерируемый контент всегда редактируется человеком, добавляем author/expert review |
| Сайд-эффект от подключения Метрики на Privacy / 152-ФЗ | Низкая | Средняя | Используем Метрику в режиме «без cookies» (`ym('getClientID', …)`) или cookie-баннер |
| Lighthouse просядет от JSON-LD / Schema.org | Низкая | Низкая | JSON-LD inline в `<head>`, не external |
| Кейс-стади с реальными учителями не получится собрать (UGC-провал) | Средняя | Средний | Делаем кейсы с командой (методист + редактор), не требуем обязательно реальных учителей |

### 11.2 Антипаттерны — чего НЕ делать

1. **❌ Плодить doorway-страницы** — каждая тема должна быть отдельной сущностью, не «вариант темы с заменой города».
2. **❌ Покупать ссылки на биржах** (Sape, Miralinks, Gogetlinks в массовом порядке) — Яндекс это пессимизирует. Только естественные упоминания и PR.
3. **❌ Спамить ключевиками в title/description** — «Рабочие листы по математике 5 класс рабочие листы скачать рабочие листы».
4. **❌ Клоакинг / разный контент для ботов и людей** — бан Яндекса.
5. **❌ Auto-generated Blog без редактуры** — Google Helpful Content Update зафильтрует.
6. **❌ Игнорировать Mobile UX** — большинство учителей с телефона.
7. **❌ Делать «сравнительные страницы» в стиле «мы лучше всех»** — Google пессимизирует гонзо-маркетинг. Только честные сравнения.
8. **❌ Плодить дубли страниц (с query params, со слешем/без)** — на каждый вариант `canonical`.

### 11.3 Stop-criteria (когда стратегия пересматривается)

| Событие | Действие |
|---|---|
| Organic < 50 визитов/день через 3 мес | Аудит, пересмотр кластеров |
| Organic < 100 визитов/день через 6 мес | Стоп, пересчёт unit-экономики |
| Lighthouse mobile < 70 | Фикс перформанса прежде чем идти дальше |
| Топ-5 конкурент запустил AI-генератор с ФГОС-фильтром и SEO-картой | Экстренный roadmap review с Иваном |
