# TZ-10 / Этап 5: Аналитика и подтверждение домена — чек-лист для PM

> Дата: 2026-09-29 · Куратор: Mavis · Источник: `docs/seo/seo-roadmap.md` §8.1, §9.1, §9.9.
> Код Яндекс.Метрики уже в репе (`src/components/analytics/YandexMetrika.tsx`). Нужно зарегаться в 4 сервисах и заполнить `.env`.

## Шаг 1 · Яндекс.Метрика (код уже готов)

| Поле | Значение |
|---|---|
| **Действие** | https://metrika.yandex.ru → «Добавить счётчик» → имя «УчЛист», домен `uchlist.ru`, включить «Вебвизор» → получить 8-значный ID. |
| **Дальше** | Вписать в `.env` (не `.env.example`): `NEXT_PUBLIC_YM_ID=98765432`. Закоммитить `.env` нельзя. |
| **Когда подхватится** | После ближайшего деплоя. Без редеплоя компонент рендерит null (безопасно). |
| **Если не работает** | Инкогнито → DevTools → Network → ищем `mc.yandex.ru/metrika/tag.js`. Нет запроса — env не пробросился в Cloudflare Pages → Settings → Environment variables. |

## Шаг 2 · Яндекс.Вебмастер

| Поле | Значение |
|---|---|
| **Действие** | https://webmaster.yandex.ru → «Добавить сайт» → `uchlist.ru` → подтвердить через **DNS TXT** (рекомендую) или **HTML-файл** в `/public/`. |
| **Дальше** | «Индексирование → Файлы Sitemap» → добавить `https://uchlist.ru/sitemap.xml`. |
| **Если не работает** | TXT не подхватился — проверить, что запись без кавычек и пробелов. Задержка подтверждения TXT — до 24ч. |

## Шаг 3 · Google Search Console

| Поле | Значение |
|---|---|
| **Действие** | https://search.google.com/search-console → «Добавить ресурс» → тип **«Домен»** → `uchlist.ru` → подтвердить через **DNS TXT** (можно ту же запись, что для Вебмастера). |
| **Дальше** | «Файлы Sitemap» → добавить `https://uchlist.ru/sitemap.xml`. |
| **Если не работает** | Дублирование TXT-записи нормально. Если GSC не видит TXT — подождать 5-10 минут. |

## Шаг 4 · Topvisor (опц., P1, ~3 000 ₽/мес)

| Поле | Значение |
|---|---|
| **Действие** | https://topvisor.com → «Добавить проект» → `uchlist.ru`, регион Россия, Яндекс+Google. |
| **Дальше** | Загрузить ~200 запросов из `seo-roadmap.md` §4 (кластеры A, B, D). Настроить еженедельный отчёт. |
| **Если не работает** | Бесплатный тариф — лимит 50 запросов. Можно начать с него, потом upgrade. |
