## Общий контекст для всех задач

**Стек проекта:**
- Next.js 14 (App Router) + TypeScript + Tailwind 3
- **Static export** (`output: "export"` в `next.config.mjs`) → Cloudflare Pages Direct Upload
- API routes НЕ работают, всё в `src/lib/`
- Лендинг: https://listai-prototype.pages.dev/
- Деплой: `wrangler pages deploy out --project-name=listai-prototype --commit-dirty=true` (БЕЗ `--branch`!)

**Критичные правила окружения (macOS, эта машина):**
- npm/node через PATH `export PATH="/opt/homebrew/opt/node/bin:/opt/homebrew/bin:$PATH"` в начале bash-сессии
- Cloudflare токены ТОЛЬКО в `.env`, НЕ коммитить
- Static export = НЕ создавать `src/app/api/*/route.ts`

**Где что лежит:**
- `src/lib/content/subjects.ts` (1301 строка) — таксономия
- `src/lib/types.ts` — доменные типы
- `src/lib/mock/generator.ts` — мок-генератор листов
- `src/lib/utils/storage.ts` — localStorage-утилита
- `src/lib/utils/limit.ts` — rate-limit
- `src/app/constructor/page.tsx` — wizard (4 шага)
- `src/app/subject/[subject]/[grade]/[topic]/page.tsx` — SEO-страница темы
- `src/components/constructor/WorksheetPreview.tsx` — превью листа
- `tailwind.config.ts` — цвета brand/accent

**Стиль кода:**
- TypeScript strict
- Tailwind, не styled-components
- Mobile-first, breakpoints 320/640/1024/1440
- Без новых зависимостей без апрува parent

## Task #1 — F-01: Расширить таксономию с 46 до 200 тем

**Owner:** worker (background ok)
**Файл:** `src/lib/content/subjects.ts`
**Зависимости:** нет (можно делать первой)
**Конкурентный зазор:** SEO exact-match, нет ни у кого в РФ

- ❌ Не удалять существующие темы
- ❌ Не делать ОГЭ/ЕГЭ-таксономию (F-04)

### DoD

- [ ] `npm run dev` → все новые темы рендерятся

## Task #2 — F-02: Presets в wizard (5 типовых сценариев)

**Owner:** worker
**Файл(ы):** `src/app/constructor/page.tsx`, новый `src/components/constructor/PresetGrid.tsx`
**Зависимости:** нет (можно параллельно с F-01)
**Конкурентный зазор:** UX wizard vs «напиши промт» у Обучай/MagicSchool/EasyClass

### Scope (внутри)
1. Создать `PresetGrid.tsx` — компонент с 5 preset-карточками
2. Интегрировать в `constructor/page.tsx` шаг 1 — после выбора класса показывать grid
3. 5 presets:
   - 🎯 **«Карточка на 15 минут»** — 5 заданий, базовая
   - 📝 **«Домашняя работа»** — 10 заданий, средняя
   - 📊 **«Проверочная по новой теме»** — 8 заданий, средняя, разные типы
   - 🖨 **«Раздаточный материал»** — 12 заданий, базовая, место для заметок
   - 🏆 **«Подготовка к ОГЭ/ЕГЭ»** — 6 заданий, повышенная, только 9/11 класс
4. Каждый preset: иконка + название + 1 строка описания
5. Переключатель «Шаблон / Свой вариант» — оба режима работают
6. Клик на preset → переход на шаг 2 с заполненными параметрами
7. Аналитика: событие `preset_selected` в `src/lib/utils/storage.ts`

### Scope (НЕ трогать)
- ❌ Не делать кастомные presets
- ❌ Не менять моковый генератор
- ❌ Не делать отдельный ОГЭ/ЕГЭ-режим (F-04)

### DoD
- [ ] 5 пресетов в `PresetGrid.tsx`
- [ ] Клик → переход с заполненными параметрами
- [ ] Переключатель «Шаблон / Свой» работает в обе стороны
- [ ] Аналитика пишется в storage
- [ ] Mobile (375×667): пресеты в 2 колонки, не уезжают
- [ ] a11y: `<button>` + `aria-label`, Tab/Enter навигация
- [ ] Edge case: выбрал preset → переключил на «Свой» → поля не падают
- [ ] Edge case: выбрал «Подготовка к ОГЭ/ЕГЭ» в 5 классе → не показывать или disabled

### Acceptance
- От выбора preset до PDF — ≤ 5 кликов и ≤ 30 секунд
- Все 5 presets на мобиле видны без вертикального скролла (допустим горизонтальный)

### Handoff для worker

## Task #3 — F-03: Превью заданий на SEO-странице темы

**Owner:** worker
**Файл:** `src/app/subject/[subject]/[grade]/[topic]/page.tsx`
**Зависимости:** нет (можно параллельно с F-01, F-02)
**Конкурентный зазор:** ↑ конверсия SEO → конструктор

### Scope (внутри)
1. Под описанием темы — блок «Примеры заданий из этой темы»
2. Показывать 2-3 задания из `examples[]` (если больше — первые 3)
3. Каждое задание — карточка с текстом и **ответом под спойлером** («Показать ответ» / «Скрыть ответ»)
4. CTA после блока: «Хотите 10 таких заданий в PDF? → Открыть конструктор» (deep-link с `?subject=X&grade=Y&topic=Z`)
5. Если `examples.length === 0` → блок и CTA НЕ рендерятся
6. CSS: блок ≤ 60vh, CTA виден без скролла после примеров

### Scope (НЕ трогать)
- ❌ Не показывать превью на странице предмета/класса
- ❌ Не делать интерактивное превью (где лист генерится тут же)
- ❌ Не показывать ответы сразу без клика

### DoD
- [ ] Блок рендерится под описанием темы
- [ ] Кнопка «Показать ответ» работает (toggle, без JS-багов)
- [ ] CTA ведёт на `/constructor?subject=X&grade=Y&topic=Z`
- [ ] При пустом `examples` блок и CTA не рендерятся
- [ ] Mobile: блок ≤ 60vh, CTA виден
- [ ] Edge case: тема с символами `<`, `>`, `&` в `text` — без XSS
- [ ] Edge case: тема с пустым `examples` — страница валидна, нет «пустых» CTA

### Acceptance
- Конверсия SEO → конструктор (замерит parent после раскатки)
- Нет 404 после клика на CTA

### Handoff для worker
→ Запускаю сабагента с подробным промптом.
