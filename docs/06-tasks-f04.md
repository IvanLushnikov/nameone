## Контекст для всех

**Что уже есть:**
- `/oge` — hub-страница с `ExamRunner` (варианты целиком, НЕ листы по номерам)
- `/subject/[subject]/[grade]/[topic]` — рабочие листы по темам (F-03 готово)
- `src/lib/content/subjects.ts` — таксономия обычных тем
- `src/lib/content/umk.ts` — УМК
- `src/app/constructor/page.tsx` — wizard (4 шага + presets из F-02)

**Что НЕ трогать:**
- `/oge` (hub) — оставить как есть
- `src/lib/content/subjects.ts` — это обычные темы, не экзамены
- `src/lib/types.ts` — типы предметов/классов (можно расширять, не ломать)

**Скоуп F-04:**
- Каждый номер экзамена = отдельная SEO-страница `/exam/[exam]/[subject]/[number]`
- Страница содержит: номер, тему, описание задания по ФИПИ, CTA → конструктор с предзаполненными параметрами
- Конструктор получает новый режим «По номеру ОГЭ/ЕГЭ» с выбором экзамена/предмета/номеров

**Целевой объём (минимум):**
- 5 предметов ОГЭ × ~15-20 номеров = ~80-100 страниц
- 5 предметов ЕГЭ × ~25-30 номеров = ~125-150 страниц
- Итого ~200-250 новых статических страниц

## Task #1 (F-04-A) — Таксономия ФИПИ

**Owner:** worker (background ok)
**Файл:** создать `src/lib/content/exam-taxonomy.ts`
**Зависимости:** нет
**Блокирует:** #2 и #3 (но они используют in-file заглушки пока этот файл не появится)

### Scope
1. Создать новый файл `src/lib/content/exam-taxonomy.ts`
2. Экспортировать тип `ExamNumber { exam, subject, number, slug, title, fgosRef, description }`
3. Экспортировать тип `ExamSubject { slug, title, emoji, numbers: ExamNumber[] }`
4. Экспортировать массив `EXAM_SUBJECTS: ExamSubject[]`
5. **5 предметов ОГЭ**: математика (math), русский (russian), физика (physics), информатика (informatics), обществознание (social)
6. **5 предметов ЕГЭ**: математика профильная (math-p), математика базовая (math-b), русский (russian), физика (physics), информатика (informatics)
7. **Номера — по ФИПИ 2026**:
   - ОГЭ математика: номера 1-19 (1-14 — практика, 15-19 — геометрия)
   - ОГЭ русский: номера 1-9
   - ОГЭ физика: номера 1-25
   - ОГЭ информатика: номера 1-15
   - ОГЭ обществознание: номера 1-24
   - ЕГЭ математика проф: номера 1-19
   - ЕГЭ математика база: номера 1-21
   - ЕГЭ русский: номера 1-27
   - ЕГЭ физика: номера 1-32
   - ЕГЭ информатика: номера 1-27
8. **Каждый номер** должен иметь: `slug` (транслит, kebab-case), `title` (человекочитаемое), `fgosRef` (раздел ФИПИ/кодификатор), `description` (1-2 предложения о задании)
9. **Helper функция** `getExamNumber(exam, subject, number)` — поиск по параметрам
10. **Helper функция** `getExamSubject(exam, subject)` — получить предмет целиком

### Out-of-scope
- ❌ НЕ создавать примеры заданий (это не в скоупе этого ТЗ)
- ❌ НЕ менять `src/lib/types.ts`
- ❌ НЕ менять `/oge` (hub)
- ❌ НЕ интегрировать в конструктор (это #3)

### DoD
- [ ] Файл создан, экспортирует `EXAM_SUBJECTS`, `ExamNumber`, `ExamSubject`, `getExamNumber`, `getExamSubject`
- [ ] ≥ 5 предметов ОГЭ + ≥ 5 предметов ЕГЭ
- [ ] Всего ≥ 200 номеров (сумма по всем предметам)
- [ ] Каждый номер имеет все обязательные поля (slug/title/fgosRef/description)
- [ ] `npm run build` проходит
- [ ] TypeScript strict компилируется без ошибок

### Acceptance
- `EXAM_SUBJECTS.length === 10`
- Сумма `EXAM_SUBJECTS[i].numbers.length` ≥ 200
- Все `slug` уникальны в пределах предмета
- Все `number` — положительные целые

## Task #2 (F-04-B) — SEO-страницы по номерам ФИПИ

**Owner:** worker
**Файл:** создать `src/app/exam/[exam]/[subject]/[number]/page.tsx`
**Зависимости:** НЕТ (использует in-file заглушку для dev, заменит на `exam-taxonomy.ts` после #1)

### Scope
1. Создать файл `src/app/exam/[exam]/[subject]/[number]/page.tsx`
2. **`generateStaticParams`** — генерирует пути по всем номерам ФИПИ. Использует **in-file заглушку** (минимум 5 номеров: 1-5 для ОГЭ математика и ЕГЭ русский, для покрытия dev-режима). После появления `exam-taxonomy.ts` от #1 — заменить заглушку на импорт.
3. **Страница содержит**:
   - Breadcrumbs: Главная → ОГЭ/ЕГЭ → {Предмет} → Номер {N}
   - H1: «Задание {N}. {title}» 
   - H2-блок: «Что проверяется» (description из задания)
   - H2-блок: «Примеры заданий» (заглушка «Скоро здесь появятся примеры заданий этого типа. Пока вы можете сгенерировать свой лист в конструкторе»)
   - CTA: «Сгенерировать лист по этому номеру → Открыть конструктор» с deep-link `/constructor?exam={exam}&subject={subject}&number={number}`
   - Related: «Другие номера ОГЭ/ЕГЭ по {предмету}» — список других номеров того же предмета
4. **Метатеги**: title, description, OG, Twitter, robots=index,follow
5. **Mobile-first**, breakpoints 320/640/1024/1440
6. **Использовать** существующие компоненты UI (`Card`, `Button`, `Badge`)

## Task #3 (F-04-C) — Режим «По номеру ОГЭ/ЕГЭ» в конструкторе

**Owner:** worker
**Файл:** `src/app/constructor/page.tsx` (модификация)
**Зависимости:** НЕТ (использует in-file заглушку с теми же 5 демо-номерами, заменит на `exam-taxonomy.ts` после #1)

### Scope
1. В `src/app/constructor/page.tsx` добавить **переключатель режима** в самом верху wizard (до шага выбора предмета):
   - **«По теме»** (текущий wizard — выбор предмета → класс → тема → параметры)
   - **«По номеру ОГЭ/ЕГЭ»** (новый — выбор экзамена → предмета → номеров → параметров)
2. Состояние `mode: "topic" | "exam"` в начале wizard
3. Если выбран «exam», шаги:
   - **Шаг 1**: Выбор экзамена (ОГЭ / ЕГЭ) — 2 большие кнопки
   - **Шаг 2**: Выбор предмета (5-10 карточек по `exam`)
   - **Шаг 3**: Multi-select номеров (chips/tags, можно выбрать несколько)
   - **Шаг 4**: Параметры (как сейчас: count, difficulty, type)
4. **Deep-link**: если URL содержит `?exam=oge&subject=math&number=5`, открывается в режиме «exam» с уже выбранным `{exam, subject, number: 5}`. Number превращается в chip, остальные номера того же предмета — на выбор.
5. **Аналитика**: `exam_mode_selected` событие в `src/lib/utils/storage.ts`
6. **Стилистика**: используй `PresetGrid.tsx` как референс (похожая структура card-grid)

### In-file заглушка
Создай в начале `page.tsx` (или в отдельном файле `src/lib/content/exam-numbers-stub.ts`):

  { exam: "oge", subject: "math", number: 1, title: "..." },
  { exam: "oge", subject: "math", number: 2, title: "..." },
  // ... минимум 10 номеров

После появления `exam-taxonomy.ts` от #1 — заменить на реальный импорт.

- ❌ НЕ делать отдельный ОГЭ/ЕГЭ-reжим в F-02 presets (это отдельная фича)
