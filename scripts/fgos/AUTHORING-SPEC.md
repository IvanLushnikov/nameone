# Как составить темы и задания из куска федеральной программы

Этот файл — контракт для саб-агента. Прочитай его целиком перед работой.

## Что на входе

Файл куска: `work/fgos/chunks/<имя>.json`. В нём:

- `name` — имя куска;
- `subject`, `grade` — предмет и класс;
- `statements` — массив объектов `{ "title": "...", "fgosRef": "..." }`, где `title` — высказывание из федеральной рабочей программы по этому предмету и классу.

Высказывание — это **не готовое название темы**. По гуманитарным предметам это длинные предложения («Приставка. Написание приставок.»), по точным наукам — короткие формулировки («Прямоугольная система координат»). Разбираться с этим нужно в каждом случае отдельно, смотри раздел «Название темы».

## Что на выходе

Один файл: `data/fgos/authored/<имя куска>.json`.

```json
{
  "source": "<имя куска>",
  "topics": [
    {
      "statement": "<высказывание из входного файла ДОСЛОВНО>",
      "title": "<короткое название темы>",
      "examples": [
        { "text": "<задание>", "answer": "<краткий ответ>" },
        { "text": "<задание>", "answer": "<краткий ответ>" }
      ]
    }
  ]
}
```

Правила:

- Объектов в `topics` ровно столько же, сколько высказываний в `statements`. Ничего не пропускай, не объединяй, не добавляй лишнего.
- Порядок совпадает с порядком во входном файле.
- `statement` копируется из входных данных дословно, без правок и сокращений. По нему потом собирается привязка темы к программе.
- В `examples` ровно два задания. В `title` — от 2 до 6 слов.
- Файл — чистый JSON: без ```` ``` ````, без комментариев, без текста вокруг.

## Название темы

Название — то, что учитель вбивает в поиск: «Приставка», «Морфемный разбор», «Сложное предложение», «Прямоугольная система координат», «Диалог».

- 2–6 слов, с большой буквы, без точки в конце.
- Существительное или устойчивое сочетание, а не пересказ предложения.
- Название должно различаться у соседних тем. Если две темы программы про одно и то же, разведи их по разным словам: «Орфоэпия», «Орфоэпические ошибки».
- Если высказывание уже является коротким названием темы («Сложение и вычитание»), верни его почти без изменений, убрав хвостовую часть вроде «и их свойства», если она перегружает.
- Одинаковых названий в одном куске быть не должно.

## Задания

Два задания по теме на уровне указанного класса.

- `text` — формулировка задания так, как её даёт учитель: что сделать, с каким материалом, куда записать. Длина 1–2 предложения.
- `answer` — правильный краткий ответ, 1–12 слов. Не «ответ зависит от ученика» и не рассуждение: если задание требует выписать знаки — пиши сами знаки, если составить слово — пиши слово.
- Два задания должны различаться приёмом, а не быть одним и тем же с другими словами.
- Опора на русский школьный формат: «Расставьте знаки препинания», «Найдите в тексте», «Спишите, раскрывая скобки», «Впишите гласную», «Составьте из данных слов», «Определите, какова связь», «Подберите синоним», «Замените одним словом».
- Уровень класса держи строго. Для 5 класса русского — безударные окончания, суффиксы -чик-/-щик-, -ек-/-ик-, чередование -лаг-/-лож-, приставки на -с- и -з-. Правила н/нн, слитно/раздельно с прилагательными и приставки на -с- перед з — это 7–8 класс, не подходит.
- Задание должно решаться. Если формулировка предполагает свободный текст сочинения, всё равно дай в `answer` проверяемый ориентир: какие элементы должны быть («три деепричастных оборота и одно сложное предложение»), а не «на ваше усмотрение».
- Никаких придуманных номеров параграфов, страниц учебника и ссылок на автора учебника.

## Проверка перед сдачей

1. `JSON.parse` файла проходит.
2. `topics.length` равен `statements.length` во входном файле.
3. Все `statement` совпадают с входными посимвольно, порядок сохранён.
4. У каждого объекта: непустые `title` и `statement`, ровно два примера с непустыми `text` и `answer`.
5. Все `title` уникальны внутри куска.
6. Ни один заголовок не длиннее 45 символов.

## Чего не делать

- Не менять другие файлы проекта. Ты пишешь ровно один свой файл.
- Не выдумывать содержание программы: высказывание уже дано, нужно только дать ему название и задания.
